# Explainability

## Inputs
The auditor consumes a user-supplied JSON policy description containing a principal, permission strings, resource patterns, and optional contextual controls. It does not fetch external policy data.

## Decision
Rules flag broad permission or resource wildcards, write/admin access in production, missing network restrictions, missing MFA for privileged access, absent expiry, and empty or missing resource scope. Findings include the specific input evidence that triggered each rule. The triage score is a deterministic heuristic.

## Limits
The rules are generic and cannot fully interpret provider-specific policy languages, inherited permissions, identity relationships, runtime authorization behavior, or compensating controls. A human security owner must validate findings before acting.

## Tool: inspect-access-policy
### Inputs and Data Sources
A local JSON policy object supplied by the user.
### Decision and Reasoning
Checks required structure and normalizes relevant fields for later rules.
### Outputs and Evidence
Returns normalized policy fields and input validation errors.
### Limits and Constraints
Does not validate against a provider's official schema.
### Failure Handling
Rejects malformed JSON or incorrect field types with a clear error.
### Human Review
Confirm the input represents the deployed policy and includes inherited controls.

## Tool: analyze-permissions
### Inputs and Data Sources
Normalized permissions, resources, environment, and optional controls.
### Decision and Reasoning
Applies deterministic rules for broad grants and missing controls.
### Outputs and Evidence
Returns severity, rule identifier, evidence, and remediation guidance.
### Limits and Constraints
Rule matches are indicators, not proof of exploitation.
### Failure Handling
Reports invalid or absent fields instead of inventing values.
### Human Review
Check provider semantics, business need, and compensating controls.

## Tool: generate-audit-report
### Inputs and Data Sources
Normalized policy and findings generated by the analyzer.
### Decision and Reasoning
Calculates a bounded heuristic score and groups findings by severity.
### Outputs and Evidence
Produces JSON suitable for human review and ticket creation.
### Limits and Constraints
The score is not a probability, certification, or compliance rating.
### Failure Handling
Uses an empty findings list only when analysis actually returned none.
### Human Review
Have the service owner approve changes and verify them in a controlled environment.
